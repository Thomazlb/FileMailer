# Roadmap

The first public release focuses on review-first Gmail sending from Finder.

Potential later work:

- direct multimodal Foundation Models input after Golden Gate APIs stabilize;
- explicitly opted-in Private Cloud Compute with entitlement checks;
- separately consented Gmail metadata import after restricted-scope review;
- richer pending-draft management;
- signed Homebrew Cask distribution;
- App Intents that create and open a draft but never send;
- more legacy document format analysis through public Quick Look paths.

None of these items changes the rule that every send requires an editable,
visible review window.
