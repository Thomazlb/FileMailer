# Support

Use the public
[FileMailer issue tracker](https://github.com/Thomazlb/FileMailer/issues) for
reproducible bugs and feature requests that contain no personal information.

Before submitting a report, replace email addresses, file names, paths, message
content and account identifiers with synthetic values. Do not attach personal
documents, OAuth responses, tokens or exported diagnostics that have not been
reviewed.

Security vulnerabilities must use
[GitHub private vulnerability reporting](https://github.com/Thomazlb/FileMailer/security/advisories/new)
instead of a public issue.
