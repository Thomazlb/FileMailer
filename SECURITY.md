# Security policy

Do not open a public issue for a vulnerability that could expose OAuth tokens,
messages or local files. Use GitHub private vulnerability reporting for the
repository. Include the affected version, reproduction steps and impact, but
remove all personal data and credentials.

[Report a vulnerability privately](https://github.com/Thomazlb/FileMailer/security/advisories/new).

Supported releases are the latest tagged release and the current default
branch. Acknowledgement and remediation timelines depend on severity and the
availability of the macOS 26 and macOS 27 SDK toolchains.

The detailed threat model and engineering controls are in
`docs/SECURITY.md`.
