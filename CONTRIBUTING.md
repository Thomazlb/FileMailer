# Contributing

Use Xcode 27 and the macOS 27 SDK. FileMailer deploys to macOS 26; Apple
Intelligence code must remain gated to macOS 27 or later. Keep secrets in
`Config/Local.xcconfig` or CI secret storage. Generate the Xcode project from
`project.yml`; do not make lasting structural edits only in the generated
project.

Before opening a pull request:

```bash
make audit-public
make generate
make test
make build CODE_SIGNING_ALLOWED=NO
git diff --check
```

Changes to OAuth, IPC, MIME, archive handling, logging or model prompts require
focused tests and a security review. Never add user documents as fixtures.
Use synthetic files generated by `Scripts/generate_test_fixtures.py`.

Reports and code must not contain access tokens, refresh tokens, message bodies,
private file paths or extracted content.
