# FileMailer pour Icon Composer

Les quatre fichiers utilisent exactement le même canevas `1024 × 1024`.

Ordre d’import des calques dans Icon Composer :

1. `01-Background.svg`
2. `02-WhitePlane.svg`
3. `03-BluePlane.svg`

`FileMailerIcon.svg` contient les trois calques réunis pour prévisualiser le résultat.

Couleurs :

- Fond : `#000000`
- Partie blanche : `#FFFFFF`
- Partie bleue : `#0A84FF`

Les formes ne contiennent aucun dégradé, filtre, masque, ombre ou image matricielle.
